# Release Notes v1.6.0

## New Features
- **Drag and Drop Task Reordering**: You can now reorder tasks in your task list by simply dragging and dropping them! Organize your day exactly how you want it.

## Bug Fixes
- **Task List Layout**: Fixed an issue where the task list content would be cut off at the bottom. The list now fills the available space correctly.

## Improvements
- **UI Updates**: Added visual cues when dragging tasks to indicate drop targets.
